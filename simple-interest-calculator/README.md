# Simple Interest Calculator

A simple web application that calculates simple interest based on the principal amount, interest rate, and number of years.

## Features

- Enter principal amount.
- Select interest rate using a slider.
- Enter the number of years.
- Calculate the total amount with simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100
